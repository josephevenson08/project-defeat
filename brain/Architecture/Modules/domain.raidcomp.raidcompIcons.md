# domain.raidcomp.raidcompIcons

`src/domain/raidcomp/raidcompIcons.ts` · **domain** layer · 37 lines

From the top of the file:

> Icon names for the raid planner, generated by `tools/ingest/ingest-raidcomp-icons.mjs`.
> 
> Names only. Resolving one to a path is a UI concern and stays out of `domain/`, the same split
> `domain/icons` already keeps for items and gems — see `ItemIcon` for the rendering side.
> 
> **A spec has no icon of its own in TBC.** The convention is the tree's deepest talent — Mangle for
> Feral, Shadowstep for Subtlety, Avenger's Shield for Protection Paladin — so these are derived from
> talent data already in the repo rather than fetched. The talent each one came from is recorded in
> the JSON, so the choice is auditable rather than magic.
