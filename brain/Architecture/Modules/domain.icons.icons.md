# domain.icons.icons

`src/domain/icons/icons.ts` · **domain** layer · 29 lines

From the top of the file:

> Wowhead icon *names* for every catalogued item and gem, generated by `tools/ingest/ingest-icons.mjs`.
> 
> 4,740 entries map to 1,238 distinct icons — items share artwork heavily, which is why vendoring the
> art is 2.1 MB rather than the tens of megabytes a per-item estimate suggests.
> 
> This module deliberately knows nothing about where the artwork lives or how a URL is built. The
> name is the durable fact and comes from MIT-licensed upstream data pinned to the same commit as the
> item catalogue; resolving it to a path is a UI concern, and doing it here would drag Vite's
> `import.meta.env` into the domain layer for no gain. See `ItemIcon` for the rendering side.
