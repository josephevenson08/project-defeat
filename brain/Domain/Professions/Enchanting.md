# Enchanting

**Crafting** profession



## Skill tiers

- **Apprentice** — skill 1–75, level 5+ · Any profession trainer for this skill in a major Azeroth city (Stormwind, Ironforge, Darnassus, Exodar / Orgrimmar, Undercity, Thunder Bluff, Silvermoon).
- **Journeyman** — skill 75–150, level 10+ · Any profession trainer for this skill in a major Azeroth city (Stormwind, Ironforge, Darnassus, Exodar / Orgrimmar, Undercity, Thunder Bluff, Silvermoon).
- **Expert** — skill 150–225, level 20+ · Any profession trainer for this skill in a major Azeroth city (Stormwind, Ironforge, Darnassus, Exodar / Orgrimmar, Undercity, Thunder Bluff, Silvermoon).
- **Artisan** — skill 225–300, level 35+ · Any profession trainer for this skill in a major Azeroth city (Stormwind, Ironforge, Darnassus, Exodar / Orgrimmar, Undercity, Thunder Bluff, Silvermoon).
- **Master** — skill 300–375, level 50+ · Master Enchanting trainer in Outland: Johan Barnes (Alliance, Honor Hold) / Felannia (Horde, Thrallmar); neutral options Asarnan (Consortium, Stormspire, Netherstorm) or High Enchanter Bardolan (Scryers, Shattrath, requires Scryers reputation).



## Leveling path

- skill 1–300: **Standard vanilla enchant progression (weapon/armor enchants using Strange/Soul/Vision Dust etc.)** — Trainer-taught, supplemented by disenchanting drops for materials.
- skill 300–305: **Enchant Cloak - Superior Defense** — Master Enchanting trainer (Outland). · Illusion Dust
- skill 305–320: **Enchant Bracer - Superior Stamina** — BoE formula, commonly bought off the auction house. · Illusion Dust, Arcane Dust
- skill 320–335: **Runed Arcanite Rod (crafting rank-up item, not a gear enchant)** — Formula sold by a vendor in Moonglade.
- skill 335–340: **Enchant Shield - Resilience** — Master Enchanting trainer (Outland). · Prismatic Shard, Lesser Planar Essence
- skill 340–360: **Continued dust/essence-based enchants (weapon and armor lines)** — Master Enchanting trainer (Outland).
- skill 360–375: **High-end ring enchants (e.g. Enchant Ring - Spellpower / Stats)** — Reputation vendors (Keepers of Time, The Sha'tar); requires meeting the relevant reputation threshold.
