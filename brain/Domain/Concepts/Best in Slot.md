# Best in Slot

_Per-spec ranked item lists, phase-scoped._

A BiS list in this project is a ranked list per class/spec/phase/slot, not a single answer. Each entry carries its source (raid, boss, vendor, reputation, crafting) so the list doubles as an acquisition plan rather than just a target.

All 27 specs have Phase 1/2 starter rankings. They are guide-shaped rather than tooltip-audited: items whose stats were approximated are flagged so the UI can say so. See [[Needs Verification]].
