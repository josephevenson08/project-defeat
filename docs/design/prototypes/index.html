Round 3 · 6 concepts

Immersive 3D, motion, and neumorphism, pushed hard

Three styles taken as far as they go, each built on the Launcher and on the Portal. (The Hybrid versions were dropped after review.) The 3D pieces run live WebGL scenes; give them a moment to load.

Launcher and Portal in six styles

Directions 05 and 08 were picked, then each was redone in six visual styles: minimalism, skeuomorphism, glassmorphism, neo-brutalism, Bauhaus, and motion. Same structure and data; only the visual language changes.
