What this is TBC Classic Anniversary · Phase 2

A planner for damage dealers. Pick a class and spec, gear all 17 slots against Wowhead's Phase 2 rankings, apply raid buffs, and get an estimated DPS against a fixed raid boss. The other tabs answer the questions around that: who to bring, where specs stand, what drops where, and which profession pays off at 70.

  • Real data only. Items, rankings and drops come from the app's data files, each with its source.
  • Built for DPS. Healer and tank rankings are shown for raid planning; gearing and simulation target DPS specs.
  • Nothing uploaded. A character import stays in your browser.

What changed in the data project log · updated 30 Sep

  • 30 Sep 2026Gear dataWeapon and ranged enchants filled in from the guides

    Arms and Fury Warriors gain weapon enchants, Rogue off hands are no longer bare, and the recommended scopes are in: Khorium for Warriors, Stabilized Eternium for Rogues and Hunters. 20 entries changed; no gem moved.

  • 28 Sep 2026ImportYour in-game character imports as itself

    The exporter addon was run in game. Gear from later phases is now worn rather than swapped out; only the recommendations stop at Phase 2.

  • 23 Sep 2026SimulationNo score without a weapon

    A missing weapon is named above the estimate instead of a confident number with nothing behind it.

  • 20 Sep 2026BuildsShare a build as a link; empty slots survive save and load

    The whole build travels in the link and is never uploaded. Empty slots no longer come back wearing default items.

Import your character in-game addon

Already playing? In game, run /pdexport, press Ctrl+C, and paste it here. Nothing is uploaded: the string never leaves your browser, and it carries no character name or realm.
